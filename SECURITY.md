# 安全策略 / Security Policy

## 报告安全问题

请不要在公开 Issue 中披露尚未修复的漏洞、凭据或真实访问地址。

Do not disclose unpatched vulnerabilities, credentials, or live access URLs in a public issue. 

## 范围 / Scope

重点关注：目录穿越、权限绕过、凭据泄露、命令注入、DNS/隧道错误归属、访问日志中的敏感数据，以及管理控制台被远程访问。

High-priority reports include path traversal, authorization bypass, credential leakage, command injection, incorrect DNS/tunnel ownership, sensitive access-log data, and remote exposure of the management interface.
